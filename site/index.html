How the data gets here

Every weekday after the US close, a GitHub Action runs this pipeline. If any data test fails, nothing is published and the last good version stays live.

  1. Extract & loadPython pulls daily prices and quarterly revenue from Yahoo Finance into Parquet files. Incremental, idempotent, and it reloads a ticker if history changed upstream (splits, dividends).
  2. Transformdbt models on DuckDB: staging → returns → marts for prices, risk, beta, correlation, revenue.
  3. Testdbt data tests: uniqueness, valid ranges, OHLC consistency, no missing weeks, freshness.
  4. ServeMarts exported as JSON for these charts and Parquet for the SQL console below, then deployed to GitHub Pages.

    Query the warehouse yourself

    This runs real SQL in your browser with DuckDB (WebAssembly) on the published marts (also downloadable as Parquet): fct_daily_prices, mart_ticker_summary, mart_return_correlation, fct_quarterly_revenue, mart_monthly_returns.

    Ctrl/⌘ + Enter to run. The engine (about 8 MB) loads the first time.

    Methods

    • Returns use dividend-adjusted closes, so they are total returns.
    • Volatility = standard deviation of daily returns × √252. Max drawdown is peak-to-trough inside the last 12 months.
    • Beta = slope of the stock's daily returns regressed on SPY's over the last 12 months.
    • Return per risk = 12-month return ÷ 12-month volatility (a Sharpe ratio without the risk-free rate).
    • Validated against the previous pandas version of this project: the SQL marts reproduce its published figures (tested in CI).
